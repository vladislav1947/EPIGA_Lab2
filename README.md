# Лабораторная работа № 2

## Генетический алгоритм для дискретной задачи с ограничениями

Дисциплина «Эволюционное программирование и генетические алгоритмы».

## Индивидуальный вариант

| Параметр | Значение |
| --- | --- |
| `N` | 15 |
| `Q` | 1 (группа 517) |
| `Y` | 26 |
| **Вариант** `V = 1 + ((17N + 7Q + Y) mod 20)` | **9** |
| Задача | **Назначение аудиторий занятиям с конфликтами по времени и вместимости** |
| Представление | **Вектор назначений + ремонт** |

## Постановка задачи

Дано `n` занятий (временной слот `t_i`, число студентов `s_i`) и `m`
аудиторий с вместимостями `c_j`. Требуется назначить каждое занятие одной
аудитории (вектор назначений `a`, `a_i ∈ {0, …, m−1}`) при ограничениях:

1. `c[a_i] ≥ s_i` для всех занятий (вместимость);
2. занятия в одной аудитории — в разных слотах (временные конфликты).

Цель: минимум числа используемых аудиторий, затем минимум суммарных
свободных мест. Приспособленность (максимизация):
`fit(a) = (m − rooms(a))·K − waste(a)`, где `K = n·max_cap + 1`.

## Входные данные

Данные синтетические, генерируются детерминированно (`problem.generate_instance`,
`seed = 42`), сохраняются в `data/`:

- `data/classes.csv` — таблица занятий: id, временной слот, число студентов;
- `data/rooms.csv` — таблица аудиторий: id, вместимость;
- `data/instance.json` — полный экземпляр и параметры генерации.

Процедура генерации: число студентов — целые из `[10, 40]`, слоты
распределены сбалансированно (по 5 занятий на слот), вместимости
`[25, 30, 35, 40, 50, 60, 80, 110]`. Масштаб: `n = 25 ≥ 20` занятий,
`m = 8 ≥ 5` аудиторий, в каждом слоте `C(5,2) = 10` потенциальных
конфликтных пар.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `problem.py` | Экземпляр задачи, генерация данных, проверка допустимости, ремонт, штрафная функция, конструктивные эвристики |
| `ga.py` | ГА: вектор назначений, турнирная/ранговая селекция, одноточечный/двухточечный/равномерный кроссовер, случайная мутация и специализированная мутация-перемещение, элитизм |
| `baseline.py` | Жадная конструктивная эвристика и случайный допустимый поиск |

| `experiments.py` | Все обязательные эксперименты |
| `plots.py` | Графики (требуется matplotlib) |
| `main.py` | Интерфейс командной строки |
| `test_ga.py` | Самопроверка операторов и обработки ограничений |

Ядро написано на чистом Python (3.9+) без сторонних библиотек.

## Установка

```bash
python3 -m venv .venv
.venv/bin/python -m pip install matplotlib     # только для графиков
```

## Запуск

```bash
# 1) Полный набор обязательных экспериментов
python3 experiments.py

# 2) Один запуск ГА
python3 main.py run --seed 42

# 3) Способ обработки ограничений: штрафы вместо ремонта
python3 main.py run --constraint penalty --alpha 200 --beta 1000

# 4) Сравнение способов обработки ограничений (серия запусков)
python3 main.py compare-constraints

# 5) Базовые методы
python3 main.py greedy
python3 main.py random-search --max-fe 20000

# 6) Самопроверка операторов
python3 test_ga.py
```

## Параметры алгоритма (базовая конфигурация)

| Параметр | Значение |
| --- | --- |
| Представление особи | вектор назначений `a ∈ {0,…,m−1}ⁿ`, `a_i` — аудитория занятия `i` |
| Размер популяции | 50 |
| Бюджет вычислений функции | 20 000 |
| Вероятность кроссинговера | 0.9 |
| Вероятность мутации на ген | 0.1 (flip); на особь 1.0 (move) |
| Селекция | турнирная, `k = 3` |
| Кроссовер | двухточечный |
| Мутация | случайная (flip); специализированное перемещение (move) |
| Инициализация | смешанная: ремонт + специализированная генерация |
| Обработка ограничений | ремонт (также исследуются штрафы) |
| Элитизм | 1 особь |
| Критерий остановки | лимит вычислений функции (20 000) |
| Число запусков в серии | 21 (seed 0, 1, …, 20) |

## Результаты

После запуска `python3 experiments.py` в каталоге `results/` появляются:

- `examples.csv` — примеры допустимых и недопустимых решений;
- `runs_base.csv`, `history_base.csv` — базовая серия запусков;
- `config_compare.csv` — сводная статистика по всем конфигурациям и базовым методам;
- `config_hist_*.csv` — траектории для каждой конфигурации;
- `runs_random_feasible.csv`, `history_random_feasible.csv` — случайный допустимый поиск;
- `convergence.png` — сходимость базовой конфигурации;
- `constraint_compare.png`, `constraint_boxplot.png` — способы обработки ограничений;
- `operators_compare.png` — сравнение операторов;
- `ga_vs_baselines.png`, `ga_vs_random.png` — ГА vs базовые методы;
- `best_solution.csv`, `best_solution.txt` — лучшее решение в табличном виде;
- `params.csv` — таблица параметров экспериментов.

Отчёт по работе — `report.md` (исходник) и `report.pdf` (версия для сдачи).
